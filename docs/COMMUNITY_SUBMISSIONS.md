# Community Submissions (planned)

Status: **scaffolding only in Stage 1**. Initial process will use GitHub Issues, Pull Requests, and Releases on [justhereforagoodtime42/dcc](https://github.com/justhereforagoodtime42/dcc).

## Intended actions

- Suggest a Feature
- Submit a Plugin
- Request an Official Review
- Report a Bug
- Report a Security Vulnerability (see [SECURITY.md](../SECURITY.md))
- View Contribution Guidelines / Roadmap

## Review outline

1. Submission  
2. Manifest / metadata validation  
3. Automated tests  
4. Compatibility checks  
5. Dependency and security review  
6. Maintainer source review  
7. Requested changes  
8. Approval or rejection  
9. Versioned release + registry publication  

Official status is **never** automatic from upload or CI alone.

Distinguish: official, community, local, unverified, deprecated, blocked.
